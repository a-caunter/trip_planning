# Globe geography

`land.geojson` is the unmodified Natural Earth 1:110m land dataset.

- Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
- Downloaded September 20, 2026.
- Terms: https://www.naturalearthdata.com/about/terms-of-use/

Made with Natural Earth. All Natural Earth vector and raster data is public domain.
This file is bundled locally; displaying the globe makes no requests to a map service.
